Sistem Manajemen Data (CRUD)

Aplikasi berbasis web yang dibangun menggunakan bahasa pemrograman PHP dengan menerapkan konsep MVC (Model-View-Controller). Aplikasi ini digunakan untuk mengelola data dengan fitur Create, Read, Update, dan Delete (CRUD).

Fitur
- Menampilkan data
- Menambahkan data
- Mengedit data
- Menghapus data

Teknologi
- PHP Native
- MySQL
- HTML & CSS

Struktur Folder
- config → koneksi database
- models → pengolahan data
- controllers → logika program
- views → tampilan
- index.php → file utama
  
Cara Menjalankan
1. Jalankan XAMPP
2. Aktifkan Apache & MySQL
3. Import database ke phpMyAdmin
4. Letakkan folder di `htdocs`
5. Buka browser:
   http://localhost/skincare/
